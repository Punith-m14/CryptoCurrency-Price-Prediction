# 📊 Cryptocurrency Price Analysis and Forecasting

This project focuses on analyzing and forecasting Bitcoin price movements using Python and popular data science libraries. It covers data retrieval, visualization, correlation analysis, and future price forecasting using automated machine learning models.



# 🚀 Project Overview

- **Data Collection:** Retrieved 2 years of historical Bitcoin (BTC-USD) price data using the `yfinance` API.
- **Visualization:** Created interactive candlestick charts with `plotly` to visualize price trends and market behaviors.
- **Correlation Analysis:** Performed correlation analysis to explore relationships between market indicators such as Open, High, Low, Close, Volume, and Adjusted Close prices.
- **Forecasting:** Implemented time series forecasting using the `AutoTS` library to predict Bitcoin’s closing prices for the next 30 days.



# 📦 Libraries & Tools

- Python
- `yfinance`
- `pandas`
- `plotly`
- `AutoTS`
- `datetime`



# 📈 Results

- Generated clear, interactive visualizations of Bitcoin’s price history.
- Identified key correlations between market indicators.
- Produced a 30-day forecast for Bitcoin’s closing prices using automated machine learning models.



# 📌 How to Run

1. Install dependencies:
   ```bash
   pip install yfinance plotly autots
   ```

2. Run the Jupyter Notebook:
   ```bash
   jupyter notebook crypto_curr.ipynb
   ```
